# 실험 5: 답변 모델 상한 확인 (gpt-5.4-mini)

## 왜 했나

판정 규칙 계층(`app/rules`)을 만들기로 하면서 "모델을 바꿔도 남은 오답은 줄지 않는다"고 가정했다. 이 가정은 측정한 적이 없었다. 그래서 최종 답변 모델만 더 좋은 모델로 바꿔서 확인했다.

## 조건

- **기준:** 실험 3b(`restriction_query`). 답변 모델은 gpt-4o-mini다.
- **변경:** 최종 답변 모델만 `gpt-5.4-mini-2026-03-17`로 바꿨다(`OPENAI_ANSWER_MODEL`).
  - 질의 생성, 근거 평가, 차단 재확인 모델은 그대로 두었다.
  - 검색 결과는 실험 3b 것을 그대로 썼다. 검색 차이는 없다.
  - gpt-5 계열이라 temperature를 넘기지 않았다. 추론 강도는 기본값이고, 시험 실행에서 추론 토큰은 0이었다.
- **판정 모델:** gpt-4.1. 답변 모델과 다르게 두어 자기 선호 편향을 피했다.
- **실행:** 시험셋 v1 109문항으로 3회 돌렸다.
- **비용:** 답변 모델 비용은 3회 합쳐 $1 미만이다. 답변 1회에 입력 약 1.2k 토큰, 출력 약 230 토큰이 들었다.

## 결과

| 지표 | 실험 3b | 실험 5 |
|---|---|---|
| 결론 정확도 (n=73) | 56, 56, 55 | 57, 59, 59 |
| 다수결 정답 (n=73) | 54 | 59 |
| 과잉 차단 (n=17, 낮을수록 좋음) | 6, 5, 4 | 2, 4, 3 |
| 위험 허용 (n=19, 낮을수록 좋음) | 0, 0, 0 | 0, 1, 1 |
| 지어내기 (n=10, 낮을수록 좋음) | 1, 1, 2 | 1, 0, 0 |
| 실행 간 결론 바뀜 (n=109) | 18 | 22 |

쌍대 비교(다수결, 정확 McNemar): 고침 10, 망가짐 5, **p=0.30**.

## 무엇이 바뀌었나

**고친 유형: 조건부를 불가로 읽던 오답.** 실험 3b에서 3회 모두 틀린 12문항 가운데 5문항이 고쳐졌다.

- t041 제대군인 만 36세
- t044 챗GPT 구독료 보전
- t046 통신비 이체 + 결제대행요금
- t105 체크카드로 온라인 강의 직접 결제
- t108 휴대폰 요금 카드 결제

**고치지 못한 유형: 검색에서 근거를 못 찾는 오답.**

- NO_INFO로 남은 문항: t068 국민연금, t070 해외 면접 비행기표, t082 토스 포인트, t096 게임 기획 책, t098 사업 종료 후 카드
- 그 밖에 남은 오답: t058 학자금 대출 이자, t063 개인 돈 입금
- 답변 모델은 받은 근거 안에서만 답하므로, 검색에서 빠진 근거는 모델로 복구되지 않는다.

**새로 틀린 문항: 5개.**

- **t073 피부과 레이저 시술 (위험 허용).** 2회는 조건부, 1회는 NO_INFO로 답했다. 정답은 불가다.
- **t076 해외 직구 사이트 결제.** 불가 대신 NO_INFO로 답했다.
- **t011 은행 지점에서 통장 개설.** 불가 대신 조건부로 답했다.
- **t055 월세 이체 방법.** 조건부 대신 가능으로 답했다. 채점상 오답이지만 실제 위험은 낮다.
- **t072 축의금.** 원래 2:1로 갈리던 문항이 반대쪽으로 넘어갔다.

새 모델은 "조건만 맞으면 된다" 쪽으로 기우는 경향을 보였다. 과잉 차단은 줄었지만, 그 대가로 위험 허용이 0에서 다시 생겼다.

t073과 t076은 사람 검토에서 "책자만으로 범주를 단정할 수 없다"며 `unverified_aliases`로 옮긴 표현(피부과 시술, 해외 직구)과 겹친다. 원래 판단이 어려운 문항이다.

## 해석

- **"모델을 바꿔도 줄지 않는다"는 가정은 절반만 맞았다.**
  - 조건부를 불가로 잘못 읽는 오답은 더 좋은 답변 모델로 상당 부분 줄었다.
  - 검색 누락으로 생긴 오답은 그대로 남았다.
- **전체 개선은 통계적으로 판별되지 않는다.** 다수결 54 → 59이지만 p=0.30이다.
- **안전 지표는 나빠졌다.** 위험 허용이 3회 중 2회에서 1건씩 생겼다. 결론 정확도가 올라도, 이 서비스에서 더 비싼 오류가 다시 나타났다.
- **실행 간 일관성은 좋아지지 않았다.** 결론이 바뀐 문항이 18개에서 22개로 늘었다.

## 이후 계획에 주는 영향

- 판정 규칙 계층의 근거를 "모델로는 안 된다"에서 다음으로 바꾼다.
  - **결정성:** 같은 질문에 같은 결론을 낸다.
  - **안전성:** 금지 항목의 결론을 모델 성향이 바꾸지 못한다.
  - **추적 가능성:** 결론마다 규칙 ID와 쪽수가 붙는다.
- 규칙 계층도 검색 누락형 오답(국민연금, 비행기표 등)은 직접 고치지 못한다. 규칙에 없는 항목은 RAG로 넘어가기 때문이다. 이 오답은 규칙 실험에서도 따로 센다.
- 최종 비교에서 답변 모델은 gpt-4o-mini를 유지한다. 규칙 계층의 효과를 모델 교체 효과와 섞지 않기 위해서다. 두 효과를 함께 쓰는 조합은 그 뒤에 따로 잴 수 있다.

## 한계

- 추론 강도를 올린 설정(`reasoning_effort`)은 재지 않았다. 이 결과는 gpt-5.4-mini 기본 설정의 상한이다.
- 답변 단계만 바꿨다. 질의 생성과 근거 평가 모델까지 바꾸면 검색 누락형 오답이 달라질 수 있다.
- 시험셋 v1은 여러 번 분석된 시험셋이다. 이 결과도 v1에 맞춰졌을 수 있다.
- 판정 모델(gpt-4.1)이 새 모델의 표현 방식을 다르게 채점했을 가능성을 따로 확인하지 않았다.
